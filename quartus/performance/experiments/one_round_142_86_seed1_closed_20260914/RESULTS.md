## Architecture

- One complete Keccak-f[1600] round per clock.
- Theta, rho, pi, chi, and iota are combinational between state registers.
- One Keccak-f[1600] permutation takes 24 clocks.
- Both SHAKE128 and SHAKE256 use the same core.

## Throughput

At 142.86 MHz, with 24 clocks per permutation:

- SHAKE128 permutation-only: `168 bytes * 142.86 MHz / 24` = **1.000 GB/s**.
- SHAKE256 permutation-only: `136 bytes * 142.86 MHz / 24` = **0.810 GB/s**.
- SHAKE128 including 21 input-transfer clocks: `168 * 142.86 / (24 + 21)` = **0.533 GB/s**.
- SHAKE256 including 17 input-transfer clocks: `136 * 142.86 / (24 + 17)` = **0.474 GB/s**.

These are calculated no-stall core rates, not measured FPGA/UART throughput.
